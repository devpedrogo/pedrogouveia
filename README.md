# 👨‍💻 Portfólio Pessoal | Pedro Gouveia

Uma landing page moderna e interativa desenvolvida para apresentar meus projetos, habilidades e trajetória como Desenvolvedor Backend & Fullstack Júnior. O design do projeto mistura uma estética **Neon/Cyberpunk** com elementos **Cartoonescos e de Quadrinhos** (estilo Simpsons).

## 🚀 Tecnologias Utilizadas

* **Frontend:** React, Vite
* **Estilização:** Tailwind CSS
* **Animações:** Framer Motion
* **Ícones:** Lucide React

## 🌟 Funcionalidades

* Layout totalmente responsivo (Mobile e Desktop).
* Tema escuro com efeitos de neon azul/cyan.
* Cards de projetos e habilidades com estética *Neo-brutalism* (bordas grossas e sombras duras).
* Acesso rápido e integrado para download do currículo, projetos no GitHub e LinkedIn.

## 🛠️ Como rodar o projeto localmente

1. Clone este repositório:
```bash
git clone [https://github.com/devpedrogo/nome-do-repositorio.git](https://github.com/devpedrogo/nome-do-repositorio.git)
```

2. Acesse a pasta do projeto:
```bash
cd nome-do-repositorio
```

3. Instale as dependências:
```bash
npm install
```

4. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```
